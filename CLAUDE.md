# CLAUDE.md — romkinblog-vue

## Статус

**Phase 1 (скаффолд) реализована 2026-08-13** — Nuxt-приложение работает
локально, первый git-коммит сделан. См. `PRD.md` (требования, история
решений, §11 — план фаз) и `draft/crude-idea.md` (исходная постановка
задачи, не коммитить в git). Следующий шаг — Phase 2 (генератор постов).

**Node 24+ обязателен** (см. `.nvmrc`) — CLI Nuxt использует
`node:util.styleText`, которого нет в Node 20.10. Локальный dev — `nvm use`
перед `npm install`/`npm run dev`.

## Что это

Vue/Nuxt-блог на `romkin.blog`. Практическая цель — быстро получить рабочий
блог (в отличие от `romkinblog-react`, которая учебная и идёт медленно).
Публикация статей: md + картинки → генератор → git push.

## Стек

Nuxt 3 + `@nuxt/content` v3 + Tailwind + `@nuxtjs/color-mode` + `@nuxt/icon`.
Детали и обоснование — `PRD.md` §5.
