Замыкание — это функция вместе с окружением, в котором она была создана. Внутренняя функция
сохраняет доступ к переменным внешней функции даже после того, как внешняя функция завершила
выполнение.

## Классический пример со счётчиком

```js
function createCounter() {
  let count = 0;
  return function increment() {
    count += 1;
    return count;
  };
}

const counter = createCounter();
counter(); // 1
counter(); // 2
```

Каждый вызов `createCounter()` создаёт новое, независимое замыкание — переменная `count` не
делится между разными счётчиками.

## Частая ловушка с циклами

```js
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}
// 3, 3, 3 — а не 0, 1, 2
```

Проблема в `var`: у него нет блочной области видимости, поэтому все три колбэка замыкаются на
одну и ту же переменную. Замена на `let` создаёт новую привязку `i` на каждой итерации — и вывод
становится ожидаемым: `0, 1, 2`.
